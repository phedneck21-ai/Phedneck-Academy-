# Phedneck Academy

Site estático da Phedneck Academy, preparado para publicação no GitHub Pages.

## Publicação rápida

1. Crie um repositório público no GitHub, por exemplo: `phedneck-academy`.
2. Envie **todos os ficheiros desta pasta** para a raiz do repositório.
3. Confirme que `index.html` está diretamente na raiz.
4. Abra `Settings` → `Pages`.
5. Em `Build and deployment`, selecione `Deploy from a branch`.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Clique em `Save`.
8. Aguarde a publicação. O endereço será:
   `https://SEU-USUARIO.github.io/phedneck-academy/`

## Administração

A página de gestão está em:

`admin.html`

Nesta versão, as inscrições são guardadas no navegador através de `localStorage`. A base de dados online será adicionada posteriormente.

## Estrutura principal

- `index.html` — página principal
- `admin.html` — gestão de inscrições
- `styles.css` — estilos
- `script.js` — funcionalidades
- `logo.png` — logotipo
- `.nojekyll` — publicação estática no GitHub Pages
